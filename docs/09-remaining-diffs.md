ステップ 5 までの実装を、現行版（`main` ブランチ）のコードと突き合わせた結果。機能は現行版と同等にそろっている。残っているのは、見た目・文言の細かい差と、周辺の整理だけ。

状態: **一部対応済み**（1〜3・6 と README を対応。残りは判断待ち）

## 2. 動作の差（決定済み・改善として変えたもの）

現行の不具合や、レビューで決めた変更。戻す必要はない。

- 認証: トークンの保持・更新（401 で 1 回だけ更新して再試行）、`localStorage.clear()` の廃止、サインアウト時の再生停止。
- Drive: 検索語のエスケープ順序の修正、フォルダ追加の上限（500 曲・10 段）とキャンセル、追加順（フォルダ順 → 名前順の自然順）、失敗時の再試行ボタン。
- 再生: ドラッグで並べ替えたあとの次の曲の選び方、`findIndex` の -1 の扱い、Blob URL の解放、シャッフルは 1 巡するまで重複なし、再生エラー時は次の曲へ（3 曲連続で停止）、前の曲ボタン（シングル = 頭へ / ダブル = 前の曲）、検索欄で Space を押しても再生が切り替わらない、ロック画面・イヤホンの操作（Media Session）。
- タグ: 読み取りのキャッシュを 1 キーにまとめる、「タグなし」のキャッシュ、文字化け（Shift_JIS / GBK）の補正、ロック画面へのアーティスト・アルバム表示。
- ヘッダーの「?」: 現行はバージョンの `alert`。新しい実装はデバッグ画面（`/debug`。バージョンも表示）。ボタンは設定アイコン（`settings`）に変え、リスト・耳コピのボタンと並べた（[docs/10](./10-practice-mode.md)）。
